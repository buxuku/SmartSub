## MODIFIED Requirements

### Requirement: 内置配方清单

内置配方 SHALL 至少包含四张（白话命名）：「视频 → 配音成片」（完整流水线，含默认人工把关：字幕校对开、配音确认关，主推位）、「视频 → 双语字幕」、「视频 → 字幕」、「字幕翻译」——后三张与既有三类任务语义一一对应，承接旧启动台卡片的心智与深链习惯。内置配方 SHALL 保持为任务页的无损别名：它们 MUST NOT 钉死任务配置里用户可保存的取值（例如「输出内容」），而是沿用任务页已保存的偏好；只有用户自己保存的配方才携带显式配置。

#### Scenario: 老任务类型无损承接

- **WHEN** 用户点击「视频 → 双语字幕」内置配方
- **THEN** 进入既有 generate-translate 任务页，功能与旧卡片完全一致

#### Scenario: 内置配方不改写已保存的输出内容

- **WHEN** 用户保存的「输出内容」为「仅译文」，点击「视频 → 双语字幕」内置配方
- **THEN** 任务页的「输出内容」仍为「仅译文」，没有任何内置配方携带 `translateContent`
