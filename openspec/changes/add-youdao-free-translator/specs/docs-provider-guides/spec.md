# Spec Delta: docs-provider-guides

## ADDED Requirements

### Requirement: 内置免费翻译页覆盖全部内置免费源

`docs/docs/guides/translation/free.md` SHALL 列出「自动免费翻译」与全部内置免费源（必应、谷歌、有道），并为每个源注明定位（速度与质量）、是否需要代理、批量能力与已知限制；页面展示的默认回退链顺序 MUST 与应用默认值一致。内置免费源 SHALL 继续合并为配置指南中的一个翻译服务条目，不新增独立页面；选型总览页的服务商总数保持不变，但「免费起步」路径 MUST 提及有道。

#### Scenario: 有道源的定位说明

- **WHEN** 用户阅读内置免费翻译页
- **THEN** 看到有道被描述为速度快、质量略低于必应、适合草稿的免费源，并看到已知限制（句中标签可能丢失、无标点长句质量下降）

#### Scenario: 默认链顺序与应用一致

- **WHEN** 对照文档页与 `autoFree` 的默认回退链
- **THEN** 文档中的默认顺序与应用默认值一致

#### Scenario: 选型总览提及有道

- **WHEN** 用户访问翻译服务选型总览页的「免费起步」路径
- **THEN** 可见有道免费源的说明，且总览页的服务商总数表述未因此变化

### Requirement: 有道免费源按稳定性受限服务披露

有道免费源基于非官方网页接口，内置免费翻译页 SHALL 标注其「不承诺可用性」、字幕文本会发送至有道服务器、接口变化时应用自动回退到其它源，并给出断供时的替代建议（如 AI 翻译或其它翻译服务）；页脚 MUST 更新「信息更新于」时间。

#### Scenario: 风险与替代建议可见

- **WHEN** 用户阅读内置免费翻译页中的有道说明
- **THEN** 明示其为非官方接口、不承诺可用性、文本会发送至第三方，并给出替代建议

#### Scenario: 时效性标注更新

- **WHEN** 用户浏览内置免费翻译页页脚
- **THEN** 可见更新后的「信息更新于 YYYY-MM」
