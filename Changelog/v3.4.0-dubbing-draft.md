# v3.4.0 🎙️ 字幕配音（TTS）— 草稿

> 本文件为 `add-tts-dubbing-mvp` 变更的发布说明草稿，正式发布前请核对版本号与截图。

## feat

- 新增「字幕配音」任务：字幕逐句合成为配音音轨，支持拖入字幕文件或视频自动匹配旁挂/内封字幕
  Added a "Subtitle dubbing" task: synthesize subtitle lines into a dubbing audio track; import subtitle files or drop videos with sidecar/embedded subtitles
- 本地 TTS 引擎：基于随包 sherpa-onnx worker，支持 Kokoro v1.1（中英 103 音色）与 AISHELL-3（中文 174 音色）模型下载、音色试听与 CPU 离线合成
  Local TTS via bundled sherpa-onnx worker: Kokoro v1.1 (103 voices, zh/en) and AISHELL-3 (174 Chinese voices) with in-app download, voice preview, and offline CPU synthesis
- 时长对齐管线：静音修剪 → chunk 统一变速 → ffmpeg atempo → 非重叠拼装；严格 / 平衡 / 自然三档策略；可选导出重排时间轴的对齐 SRT
  Duration alignment pipeline: silence trim → chunk-unified speed → ffmpeg atempo → non-overlapping assembly; strict / balanced / natural strategies; optional aligned SRT export
- 输出形态：同目录 `{源名}.dub.{模型}.{音色}.wav|mp3`；mp4/mkv 可选软封装附加配音轨（视频 copy、保留原音轨）
  Output: `{basename}.dub.{model}.{voice}.wav|mp3` beside source; optional soft-mux dub track on mp4/mkv (video copy, original audio kept)
- 云端 TTS：可配置多个 OpenAI 兼容服务商实例（`/v1/audio/speech`），测试连接、首次运行隐私确认与按字符数成本提示
  Cloud TTS: multiple OpenAI-compatible provider instances with connection test, first-run privacy consent, and per-character cost hint
