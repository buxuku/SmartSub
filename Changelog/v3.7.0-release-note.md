# v3.7.0 多角色配音与说话人识别，ASR 引擎再扩容

## feat

- 新增 Qwen3-ASR 1.7B 转写引擎，语音识别精度与稳定性再升级 (#411)
  New Qwen3-ASR 1.7B transcription engine for higher-accuracy, more reliable speech recognition (#411)
- 新增 Parakeet TDT 0.6B v3 转写引擎，本地转写又多一种轻量选择 (#413)
  New Parakeet TDT 0.6B v3 transcription engine as another lightweight local option (#413)
- 支持手动选择 NVIDIA CUDA 显卡进行 GPU 加速，多卡环境可按需指定 (#412)
  Choose a specific NVIDIA CUDA GPU for acceleration in multi-GPU setups (#412)
- 支持字幕说话人区分：自动识别不同发言者并标注角色 (#414)
  Speaker diarization: automatically detect and label different speakers in subtitles (#414)
- 精修页支持角色命名、纠错与批量管理，多人对话字幕编辑更高效 (#422)
  Proofread page: name, correct, and batch-manage speaker roles for multi-speaker dialogue (#422)
- 配音支持按角色批量分配音色，单句也可单独覆盖 (#423)
  Dubbing: batch-assign voices by speaker role with per-line overrides (#423)
- 支持参考文稿高置信匹配：导入原稿可自动对齐并校正转写字幕 (#415)
  Reference manuscript matching: import a script to align and correct transcription with high confidence (#415)
- 优化窗口管理与任务页布局，多窗口场景下界面更顺手
  Improved window management and task page layout for smoother multi-window use

## 下载 / Download

### homebrew (推荐)

#### 安装

```shell
brew tap buxuku/tap && brew install --cask smartsub
```

#### 更新

```shell
brew update && brew upgrade --cask smartsub
```

### 手动安装

Mac 提示应用已损坏，在终端执行

```shell
sudo xattr -dr com.apple.quarantine /Applications/SmartSub.app
```
