# v3.12.0 任务更可靠，在线下载支持导入浏览器 Cookie

## feat

- 在线下载支持按网站导入浏览器 Cookie：可从本机浏览器或文件批量导入，自动按链接匹配对应网站，轻松下载需要登录的视频
  Online download can import browser cookies per site: bulk import from a local browser or a file, and cookies are matched to the video URL automatically, making login-only videos easy to download
- 任务可从中断处继续：已完成的阶段结果会被保存并复用，修改设置后只重跑受影响的阶段
  Tasks can resume where they left off: finished stages are saved and reused, and after changing settings only the affected stages are re-run
- 向导与任务页共用同一套流程设置，两处看到的、修改的是同一份配置，工具栏布局也更紧凑
  The wizard and the task page now share the same pipeline settings, so both show and edit the same configuration, with a more compact toolbar

## fix

- 修复重启后打开自定义参数配置报错、无法加载的问题（3.9.0 起出现）
  Fix the custom parameter configuration failing to load with an error after a restart (since 3.9.0)
- 修复 CUDA 版本与已安装 Toolkit 运行时不匹配，以及加速后端状态显示过期的问题
  Fix CUDA builds not matching the installed Toolkit runtime and stale acceleration backend status
- 修复批量任务进行中，审阅字幕时会串到其他文件的问题，现在每个文件单独审阅
  Fix subtitle review reaching into other files during a running batch; each file is now reviewed on its own
- 修复 Windows 上任务产物可能未及时写入、待导出结果丢失，以及已编辑的字幕交付物和已确认的任务信息被覆盖的问题
  Fix task outputs not being fully written on Windows, pending exports getting lost, and edited deliverables or accepted task info being overwritten
- 修复视频合成时在线流媒体输入丢失，以及 MKV 内嵌字体附件未保留的问题，并提升不同视频流与编码格式的兼容性
  Fix streaming inputs being dropped and embedded font attachments in MKV not being kept when composing video, and improve compatibility with more stream and encoding formats
- 修复任务设置面板内容被裁切的问题，已取消的任务不再显示多余的阶段
  Fix the task settings panel getting clipped, and cancelled tasks no longer show phantom stages

## 下载 / Download

### homebrew (推荐)

#### 安装

```shell
brew tap buxuku/tap && brew install --cask smartsub
```

#### 更新

```shell
brew update && brew upgrade --cask smartsub
```

### 手动安装

Mac 提示应用已损坏，在终端执行

```shell
sudo xattr -dr com.apple.quarantine /Applications/SmartSub.app
```
