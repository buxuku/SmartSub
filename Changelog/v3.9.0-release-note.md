# v3.9.0 🤖 AI 创作助手登场，MCP 自动化与音视频工具箱

## feat

- 新增内置 AI 创作助手（快捷键 ⌘J / Ctrl+J），支持上下文感知、对话式字幕润色、截图排障与文件对话 (#499)
   Add in-app AI Assistant (⌘J / Ctrl+J) with context awareness, conversational subtitle polish, screenshot diagnostics, and file chat (#499)
- 支持 MCP 协议与 CLI 自动化，提供 111 个工具与统一命令行，支持一键连接 Cursor、Codex 与 Claude Code (#499)
   Support MCP and CLI automation with 111 tools and unified command line, integrating with Cursor, Codex, and Claude Code (#499)
- 新增音视频工具箱，内置音频提取、字幕合并/转换/对齐、视频压缩、裁剪与转 GIF 等实用小工具 (#487)
   Add Audio/Video Toolbox for audio extraction, subtitle merge/convert/sync, video compression, trimming, and GIF creation (#487)
- 新增字幕质量巡检，智能检测语速过快 (CPS)、单行超长与疑似漏听，支持快速试听与补全 (#496 #497)
   Add subtitle quality review to detect rapid speech rate (CPS), overly long lines, and missed speech with quick audition and repair (#496 #497)
- 支持多视频独立匹配各自的参考文稿，全局文稿移至高级设置 (#488 #498)
   Support independent manuscript matching for multi-video imports, and move global manuscript into advanced settings (#488 #498)
- faster-whisper 支持从本地压缩包或目录一键导入运行时，无需重新下载 (#495)
   Support importing faster-whisper runtime directly from local archives or folders (#495)
- 任务列表新增微阶段进度与耗时展示，并将工具箱处理记录纳入历史任务 (#498)
   Display micro-stage progress and elapsed time for tasks, and include toolbox operations in task history (#498)


## perf

- 重构校对台布局并合并工具栏，优化宽窄屏自适应与长字幕列表流畅度 (#494 #497)
   Refactor proofread layout and merge toolbars, improving responsiveness and list performance (#494 #497)
- 优化语速 (CPS) 计算逻辑，忽略空白字符并加入动态容差，减少误报 (#499)
   Optimize CPS calculation by ignoring whitespace and adding dynamic tolerance to reduce false alarms (#499)

## fix

- 修复自定义参数中嵌套对象显示为 [object Object] 的问题，支持编辑 JSON 对象并保留 thinking 配置 (感谢 @nightt5879 #477)
   Fix nested parameter objects showing as [object Object], supporting JSON object editing and thinking configs (thanks @nightt5879 #477)
- 修复翻译服务测试在接口返回错误时被误判为连通成功的问题 (感谢 @lllleolin-max #481)
   Fix provider test false positives when endpoints return structured errors (thanks @lllleolin-max #481)
- 修复 OpenAI 兼容翻译请求未走应用代理的问题，并在连接失败时停止无效探测 (#479 #483)
   Fix OpenAI-compatible translation requests not using app proxy, and stop probing on failure (#479 #483)
- 翻译部分行失败时明确提示失败行数，并允许进入校对台查看与补译 (#489)
   Show failed line count on partial translation errors and allow proofreading untranslated lines (#489)
- 优化 AI 字幕精修与翻译服务的配置联动，解决服务冲突与提示词保存问题 (#484 #485 #497)
   Improve config coordination between AI refine and translation, resolving service conflicts (#484 #485 #497)
- 过滤 Qwen-ASR 输出中的特殊控制字符，防止字幕解析与渲染异常 (#494)
   Sanitize control characters in Qwen-ASR output to prevent subtitle parsing and display errors (#494)
- 修复 Windows 下合成视频导出时偶发的 fsync EPERM 写入报错 (#494)
   Fix intermittent fsync EPERM errors when exporting composed videos on Windows (#494)

## 下载 / Download

### homebrew (推荐)

#### 安装

```shell
brew tap buxuku/tap && brew install --cask smartsub
```

#### 更新
```shell
brew update && brew upgrade --cask smartsub
```

### 手动安装

Mac 提示应用已损坏，在终端执行

```shell
sudo xattr -dr com.apple.quarantine /Applications/SmartSub.app
```
