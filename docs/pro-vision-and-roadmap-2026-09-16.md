## 1. 产品愿景与专业护城河定位

### 1.1 核心市场生态位

当前视听创作工具市场存在显著的割裂：

- **消费级剪辑工具（如剪映、CapCut）**：上手极快、交互平滑，但生态封闭、对本地开源模型和私有化部署支持极弱、强行依赖云端付费算力、时间轴导出精度粗糙。
- **传统专业字幕工具（如 Subtitle Edit、Aegisub）**：毫秒与帧率极其精确、样式控制专业，但界面陈旧、认知成本极高、缺乏现代大模型与端到端自动化流水线。
- **云端 SaaS 字幕平台**：体验优雅，但按分钟高额计费、长视频上传等待极长、面临隐私与商业机密泄露风险。

```
                    SmartSub Pro 护城河模型
                             ▲
                            / \
                           /   \
  [极速创作者体验] <--------+---+--------> [工业级精度与数据安全]
  • 30秒开箱可用             |             • 零数据丢失离开守卫
  • 场景化预设屏蔽黑话       |             • 分数级帧率与时间轴无漂移
  • 全自动化流水线           ▼             • 复杂上下文全链路恢复
                  [本地+云端混合多引擎矩阵]
                  • 涵盖主流本地/云端 ASR/TTS/LLM
                  • 离线算力自由调度，零成本隐私保障
```

### 1.2 黄金体验原则

1. **下限坚若磐石（Rock-solid Baseline）**：零工作丢失、零虚假保存、零时间漂移、状态真实可信。任何界面修饰都不能建立在“把失败显示成成功”或“切页导致未保存丢弃”的基础之上。
2. **上限生产力拉满（Pro Productivity Ceiling）**：引入波形图直接交互、画面安全框吸附、AI 润色行内 Diff、角色阵容集中分配。让专业译配人员和高产内容团队能够获得数倍于传统工具的交付效率。
3. **极客能力场景化（Presets Over Parameters）**：用“业务场景预设”包装底层黑话，把 80% 的通用参数隐藏在模板后，把 20% 的硬核控制留给专家抽屉。

## 2. 基石筑牢：承接工程审计的底线防御体系

在追求任何前沿视觉与交互创新之前，必须严格解决 `@docs/ui-ux-audit-2026-09-16.md` 中指出的关键隐患，确立四大系统级底线：

### 2.1 彻底建立「全域离开守卫」与可靠保存机制

- **路由守卫补齐（对齐 R01）**：在 `_app.tsx` 中建立全局路由拦截器（`routeChangeStart` / `beforePopState`），无论用户通过侧栏 NavLink、命令面板（Cmd+K）还是前进后退切换页面，若检测到 `isDirty`，必须弹出非阻塞式标准确认 Dialog；未保存确认放弃前阻止卸载。
- **状态与响应强绑定（对齐 R02）**：彻底修复校对批次保存无条件 `return true` 的缺陷。保存状态必须严格消费 IPC 真实响应结构：
  ```typescript
  // 严格状态流转：idle -> saving -> saved (3s auto revert) | save_error
  const res = await window.ipc.invoke('updateProofreadTask', payload);
  if (!res?.success) {
    setSaveStatus('save_error');
    toast.error(t('proofread.saveFailed', { reason: res?.error }));
    return false;
  }
  setSaveStatus('saved');
  ```
- **双层草稿容灾系统**：未开始运行的任务（`TaskWizard`）与编辑中的字幕（`ProofreadEditor`）建立内存+LocalStorage 双重草稿。遇到意外崩溃或误关，下次进入主动弹出“检测到未保存的工作草稿，是否恢复？”。

### 2.2 确立工业级数学精度与标准定义

- **严谨的丢帧与帧率换算（对齐 R06）**：废弃所有浮点估算除法，全系统采用标准分数精确定义 NTSC / PAL 广播级帧率：
  $$\text{FPS}_{23.976} = \frac{24000}{1001}, \quad \text{FPS}_{29.97} = \frac{30000}{1001}, \quad \text{FPS}_{59.94} = \frac{60000}{1001}$$
  保证一小时以上长音视频在时间校准、字幕时间轴对齐、压制时间戳计算时达到**零微秒级累积误差**。

### 2.3 状态表达真实化与语义去欺骗

- **状态栏真实解耦（对齐 R04）**：底栏“引擎就绪”不再简单挂钩加速徽章，而是解耦为多维健康度检测器（显示：“Whisper 本地模型未下载 / 硅基流动已连接 / GPU 加速可用”）。
- **消除配方文案冲突（对齐 R05）**：文案严禁标称“全自动出成品视频”却在中间字幕环节强行停靠阻塞。将门禁前置化表达为可选项：**「全自动直通出片」vs「质量把关模式（停靠校对）」**，尊重用户知情权。

## 3. 全链路模块的专业化护城河重塑

```
┌────────────────────────────────────────────────────────────────────────┐
│                        SmartSub Pro 创作主链路                          │
└────────────────────────────────────────────────────────────────────────┘
     │                    │                     │                   │
┌────▼──────────┐   ┌─────▼──────────┐   ┌──────▼──────────┐   ┌────▼──────────┐
│   在线下载    │──>│  任务构建中心  │──>│   字幕校对台    │──>│   配音工作台  │──> 压制合成
│ 预检/流式解析 │   │ 场景预设/零折行 │   │ 可视化波形/Diff │   │ 角色音色阵容  │
```

### 3.1 启动台与任务构建中心：场景化驱动与零折行架构

#### 痛点破除

当前 `InlineConfigBar` 在 1440 宽屏幕下平铺多个下拉框必然折行，界面参差不齐；且向导（`TaskWizard`）与单任务页（`tasks/[type]`）表单模型割裂，导致设置记忆互相覆盖。

#### 护城河设计

1. **任务配置栏重构为「两段式检查器（Inspector）」**：
   - **左侧核心主干（必选且紧凑，绝对不折行）**：
     `[转写引擎/模型 ▾]  →  [源语言 ▾]  →  [目标语言 ▾]  →  [翻译引擎 ▾]`
   - **右侧能力开关胶囊（点击即就地弹出卡片配置）**：
     `[ ✨ AI精修: 开启 ▾ ]   [ 📄 文稿对齐: 2个文件 ▾ ]   [ ⚙ 专家参数 ]`
2. **场景预设引擎（Presets Engine）**：
   取代冰冷的 Temperature / Beam Size / VAD Threshold 选项，首屏推荐场景预设：
   - **会议访谈 / 播客**：开启激进短句切分、说话人聚类、保留原声停顿。
   - **网课演讲 / 教程**：开启严谨去幻觉、术语强制对齐、智能去语气词（嗯、啊、就是）。
   - **影视短剧 / Vlog**：紧凑双行排版、保留情绪语气词、情感口语化翻译。
   - _（高级用户一键点击“转为专家自定义参数”即可展开精确滑块）_。
3. **“输入即草稿”闭环（对齐 R03、R08）**：
   首页任何区域均可作为大拖拽热区。用户拖入视频后，系统立即创建草稿并暂存文件路径；若发现缺少模型，提示“需安装 Whisper Base（预计耗时 15 秒）”，点击安装完成后**自动无缝回到该任务草稿，无需重新拖入文件**。

### 3.2 字幕校对工作台：从“纯文本表格”跃升为“双模可视化工作台”

#### 痛点破除

当前校对主要依靠表格和数字时分秒输入框，校准入出点极其低效；AI 优化采用全屏弹窗，无法直观对比上下文。

#### 护城河设计

1. **轻量级音频波形轨道（Waveform Timeline Track）**：
   - 在视频播放器下方集成高性能音频波形组件（支持动态缩放 Zoom In/Out）。
   - 波形图上直接以色块呈现各字幕条目的时间区间，静音段清晰可见。
   - **直觉交互手柄**：鼠标拖拽字幕块左右边缘即可修改出入点（吸附到静音边缘）；选中位置按 `C` 键原地切分字幕，按 `X` 键合并相邻字幕。
2. **行内 AI 润色 Diff 机制**：
   - 彻底废除阻塞式的大弹窗。点击单行或批量“AI 润色/缩短”后，在当前行直接展开 Diff 视图：
     ```
     原文: The quick brown fox jumps over the lazy dog.
     当前译文: 那只敏捷的棕色狐狸跃过了[懒惰的狗]。
     AI 提议:  那只敏捷的棕色狐狸跃过了[大懒狗]。(口语化优化)
     [ 接受 Enter ]   [ 忽略 Esc ]
     ```
3. **划词入库闭环（In-Context Glossary）**：
   - 校对时鼠标选中任何生词或人名，浮出快捷气泡 `[ + 加入术语表 ]`。
   - 弹窗输入目标译词并设置“仅当前项目生效 / 全局生效”，确认后系统自动提示：“检测到全文还有 5 处匹配，是否一键批量更新？”
4. **排版健康度诊断指标（CPS 实时监控）**：
   - 行内自动计算 **CPS (Characters Per Second，每秒字数)** 与字符长度。
   - 当中文字幕超过 8 字/秒、英文字幕超过 20 字符/秒时，显示柔和黄标提示“阅读速度过快，建议拆分或精简”，防止成片文字闪现过快。

### 3.3 视频字幕压制与合成：所见即所得的导演画布

#### 痛点破除

当前 Jassub 预览画面纯只读，边距、位置只能通过左侧 Slider 盲调；软字幕与硬字幕参数混杂，容易产生渲染误解。

#### 护城河设计

1. **画布直接操控与安全区参考线（Direct Manipulation Canvas）**：
   - 鼠标悬浮在预览视频上，字幕块呈现可拖拽的虚线包围盒。直接拖拽即可调整字幕在画面中的绝对 Y 轴位置。
   - 提供标准平台遮罩层一键开关：
     - **短视频平台模式（TikTok / 抖音）**：半透明覆盖右侧点赞头像、底部标题评论区遮挡范围，确保字幕落在可见安全区域内。
     - **影视广播模式**：标准 80% / 90% 标题与动作安全框。
2. **字体与样式所见即所得**：
   - 字体下拉菜单不再是纯文字列表，而是**直接使用该字体渲染“SmartSub 字幕示例 123”预览**。
   - 提供工业级开箱即用样式预设组：
     - _B 站知识区大字高对比_（黑底白字黄高亮）
     - _奈飞（Netflix）双语影视标准_（黄/白双行细等宽阴影）
     - _短视频综艺花字_（粗描边、倾斜外发光）
3. **模式强隔离与导出校验（对齐审计要求）**：
   - 明确分离 **「硬字幕压制（Burn-in，重编码成片）」** 与 **「软字幕封装（Muxing，免编码注入 MKV/MP4 字幕轨，毫秒级导出）」**。
   - 选定软字幕时，自动禁用描边模糊、特殊花字等可能失效的 ASS 特效配置，并提示“软字幕显示效果取决于播放器自身的渲染设置”。

### 3.4 AI 配音工作台：角色阵容矩阵与时间轴自适应

#### 痛点破除

多说话人（Speaker）分配繁琐，长短句语音常常突破字幕原本时间区间，导致与画面口型或情节严重脱节。

#### 护城河设计

1. **角色阵容卡片（Voice Cast Matrix）**：
   - 列表顶部常驻识别出的说话人面板：
     `[ 说话人 1 (主讲人) • 42句 • [选择音色 ▾] • 试听 ]   [ 说话人 2 (提问者) • 12句 • [选择音色 ▾] • 试听 ]`
   - 一处改动，全篇该角色的音频生成配置统一绑定，支持统一微调语速和音高。
2. **音色资源库抽屉（Voice Library Drawer）**：
   - 替代单调的长下拉框，点击唤出抽屉式音色库：
     - 支持按 **性别（男/女/儿童）、风格（新闻旁白/温暖故事/激昂解说/动漫二次元）、语言** 多维筛选。
     - 鼠标悬浮卡片自动即时流式试听 3 秒代表作。
3. **时空对齐自适应引擎（Auto-fit Speech Rate）**：
   - 当生成的 TTS 音频超出该字幕时间轴时：
     - **超限 < 15%**：启用算法级无损变调变速（Time-stretch without Pitch Shift），自动压进区间内。
     - **超限 > 15%**：在行上直观呈现红条对比（如：“超限 +0.8s”），提供两个一键解决方案：
       - `[ ⚡ AI 缩写提炼译文 ]`（减少字数再合成）
       - `[ 顺延后续空白区间 ]`（在不与后文撞车的前提下自动借用空闲时间段）。

### 3.5 视频下载中心与工具箱：破除孤岛，构建闭环资产链路

#### 痛点破除

当前 8 个子工具如同单机软件，生成结果后只能点击“打开文件夹”；视频下载完成后需要重新进入向导选文件。

#### 护城河设计

1. **下载后“直通车”流水线自动化（Download-to-Pipeline）**：
   - 在下载面板提供配置项：`[✓] 下载完成后自动启动创作流水线`。
   - 支持批量抓取 YouTube/B站 原生字幕轨。如果视频自带高精度官方字幕，后续流水线自动跳过 ASR 转写阶段，直接进入双语翻译或配音环节，节省 90% 算力与时间。
2. **工具箱闭环行动条（Actionable Finish Bar）**：
   - 统一 8 个工具的处理完成界面：
     ```
     ✅ 处理完成：output_video_trimmed.mp4 (48.2 MB)
     [ 📂 打开所在文件夹 ]  [ 🚀 去做双语字幕 ]  [ 🎙 去做 AI 配音 ]  [ ✂ 继续截取 ]
     ```
3. **全工具批量队列支持（Batch Queue）**：
   - 格式转换、音频提取、视频压缩等工具全面支持一次拖入多个文件，显示独立进度条与失败项重试。

## 4. 界面规范与人机工学治理 (Design & Ergonomics)

| 规范领域         | 现状问题                     | 专业版重构标准                                                                                                                                                                                                          |
| :--------------- | :--------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **空间与响应性** | 缺乏小屏约束，依赖大宽度     | **绝对支持 $1024 \times 700$ 最小窗口**；在主流 13 吋笔记本屏幕（$1440 \times 900$ 缩放）下绝不出现页面级横向滚动条；属性面板支持一键快捷收折（Cmd+B）。                                                                |
| **视觉层级**     | 细线边框嵌套重叠，卡片套表格 | **表面层次系统（Surface Hierarchy）**：弃用多层 1px border，改用微透明度中性面分层（`bg-background` -> `bg-muted/40` -> `bg-card`）；保留 Studio Blue 品牌主行动色，弱化无效装饰。                                      |
| **键盘效率**     | 输入聚焦时快捷键冲突、缺失   | **影视非编级全键盘流（NLE Keyboard Flow）**：<br>• 空格：播放/暂停视频<br>• `Tab / Shift+Tab`：在当前行原文与译文框流转<br>• `Cmd+Enter`：快速完成当前行并跳转下一行<br>• `Cmd+Z / Cmd+Shift+Z`：毫秒级全历史撤销重做。 |
| **状态一致性**   | 瞬时 Toast 容易遗漏关键故障  | 统一采用“行内警示条（Banner）+ 错误可折叠详情”机制，关键错误必须常驻在任务卡片上，包含明确的一键修复建议，避免一闪而过的弹窗。                                                                                          |
