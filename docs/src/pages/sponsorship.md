# 赞助合作

SmartSub（妙幕）是一个开源免费的本地 AI 字幕工具，由个人作者持续维护。如果你的产品或服务与**视频、字幕、AI 模型、音视频工具、内容创作**等方向相关，欢迎联系我探讨赞助与合作。

## 合作形式

- **特别赞助**：在 GitHub README 顶部与官网展示品牌标识及介绍，目前为 CrazyToken。
- **赞助商**：在 README「赞助商」栏目展示 Logo 与链接。
- **服务集成**：与翻译、转写、配音等 API 服务做内置集成与联合推广。
- **其他**：软件内推荐位、联合活动、定制开发等，可直接说明你的想法。

## 沟通须知

为了让沟通更高效，请在**首次联系时**一次性说明以下信息：

1. 公司 / 产品名称与官网链接
2. 希望的合作形式
3. 简要的合作诉求与预算范围（如已有）

邮件标题请以 **`[赞助合作]`** 开头；QQ 添加好友时请备注 **`赞助合作 + 公司/产品名`**，没有备注的验证请求会被忽略。

以下内容将不会回复：

- 与 SmartSub 用户（字幕、视频创作者）无关的推广，如博彩、成人、灰色产业、代刷代充等
- SEO 外链、软文代发、群发式的推广邮件或消息
- 没有任何具体信息的「在吗」「有合作吗」
