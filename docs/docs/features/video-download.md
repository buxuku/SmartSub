# 在线视频下载

想给网上的视频做字幕，不用先找第三方下载工具——粘贴链接即可下载，完成后一键进入字幕任务。

## 双下载引擎

| 引擎       | 覆盖                         |
| ---------- | ---------------------------- |
| **yt-dlp** | YouTube 及 1800+ 站点        |
| **lux**    | B 站、抖音、小红书等国内平台 |

首次使用在页面顶部一键安装 / 更新引擎；每条链接可单独选择引擎，也可以让应用按平台自动匹配。

## 使用方式

1. 左侧导航进「下载」，把视频链接粘贴到输入框——**一行一条**，支持从聊天记录等混杂文本中自动识别链接
2. 设置保存目录、清晰度（最佳 / 指定档位）、并发数
3. 「解析链接」预览可用清晰度后下载，或「直接下载」按默认设置开始

下载任务进入最近任务列表，完成后可直接衔接转写 / 翻译任务。

## 官方字幕自动配对

勾选「同时下载官方字幕」后，平台自带的字幕（含自动生成字幕）会随视频一起下载，并在任务向导中**自动配对**——有官方字幕就无需再转写，直接进入翻译或校对，省时且更准确。

## 站点 Cookie：解锁高清与会员内容

不少平台的高清晰度或会员内容需要登录后才能访问。点「站点 Cookie」即可一次导入并自动识别站点：

1. 选择已登录的浏览器；Chrome、Edge、Brave 有多个用户档案时，可选择对应档案。
2. 点击「一键导入支持的站点」，或选择标准 Netscape 格式的 `cookies.txt` 文件。
3. 列表显示已导入的站点及有效期，无法确定到期时间时显示「未知」。下载时会自动按链接匹配，也支持 B 站、抖音、小红书等平台的短链接域名。

自动识别范围包括哔哩哔哩、YouTube、抖音、西瓜视频、快手、小红书、微博、知乎、AcFun、优酷、爱奇艺、芒果 TV、TikTok、X / Twitter、Instagram、Facebook、Vimeo、Twitch、Dailymotion、Niconico，以及之前添加的自定义站点。仅保存匹配站点的 Cookie，其它网站数据会被丢弃。

再次导入会更新匹配站点的 Cookie，不混合多个浏览器账号；本次没有发现的站点保留原数据。导入失败也不会覆盖旧档案。可用站点右侧的「清空」移除单个站点，或点击「清空全部」移除本软件保存的全部 Cookie；浏览器中的登录数据不受影响。

界面仅提供浏览器一键导入和 `cookies.txt` 文件导入。自动识别只保存各平台公开站点主机及适用父域的 Cookie，排除创作者后台等其它主机的专用 Cookie；自动识别目录并非下载引擎的完整支持列表。

**已导入不等于登录态已验证，也不保证能下载。** 平台的接口变化或风控仍可能导致 403；更新 Cookie 不能解决所有提取器问题。浏览器的系统授权、加密限制也仍然适用，无法直接提取时可导入 `cookies.txt`。

:::caution
Cookie 等同于你的登录凭证，仅保存在本地并只用于下载请求；请勿把含 Cookie 的配置分享给他人。
:::
