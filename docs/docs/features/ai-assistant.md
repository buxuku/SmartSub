点击软件顶栏的 **AI 助手**，即可在右侧面板中对话。助手使用你在「翻译」页面配置的 AI 服务，并调用 SmartSub 的现有工具执行创作任务。

在软件内按 **⌘J（macOS）／Ctrl+J（Windows、Linux）** 可快速展开或收起助手，展开后自动聚焦聊天输入框。输入框底部也会显示该快捷键。

回复支持 Markdown 标题、列表、表格、引用和代码块。拖动面板左边缘可调整宽度，软件会记住宽度；点击助手外部或按 Escape 可收起，当前对话、输入草稿及运行中的任务会保留。

## 选择服务

当前支持 OpenAI 兼容接口，包括自定义 OpenAI 服务、DeepSeek、DeerAPI、Gemini、SiliconFlow 和通义千问。所选模型需要支持流式回复和工具调用。原生 Ollama 与 Azure OpenAI 专用接口暂不接入；传统机器翻译服务不能用于聊天。

在输入框底部、发送按钮左侧切换服务和模型。手动保存服务配置后，列表自动刷新。

聊天使用独立的创作助手提示词，不套用字幕翻译提示词或翻译 JSON 输出格式。已有 API 地址、密钥、网络代理和适用的自定义参数继续生效。密钥不会作为工作台上下文发给模型。

## 结合当前工作台

输入框上方显示本轮会引用的文件和字幕行。发送时固定上下文，之后切换页面不会改变这条指令的目标。取消勾选「引用当前上下文」可以发送不附带当前页面信息的消息；此前对话中的上下文仍保留在会话中。

可以尝试：

- 「把当前这一句改得更口语化」
- 「解释这一段字幕中的专业术语」
- 「把当前视频转成中英双语字幕并合成」
- 「查看我安装了哪些模型」
- 「刚才的任务为什么失败了」
- 「帮我看看当前界面的报错提示怎么解决」

校对页的上下文包含当前字幕、邻近内容、语言、播放位置和未保存草稿。任务页面提供输入文件、配置、状态和近期报错摘要；助手可在分析任务故障时主动查询应用与任务日志（支持按错误级别过滤）。当需要结合界面弹窗、Toast 提示或控件状态定位问题时，助手会自动调用内置截屏工具截取工作区进行多模态视觉分析；你也可以随时点击输入栏的相机按钮一键截取当前工作区作为附件发送。配音、合成页面提供当前文件和会话引用。当前版本不分析视频画面或音频内容。

## 文件聊天

点击输入框的回形针选择文件，或把文件拖入助手。每条消息最多添加 8 个附件，发送前可移除；发送失败会保留草稿。取消勾选「引用当前上下文」，即可在新会话中只围绕附件聊天。

- 字幕（SRT、VTT、ASS、SSA、LRC）、参考文稿（TXT、MD、Markdown）和 JSON 校对／配置文件：只提供本地路径，由助手按需调用软件现有 MCP 工具读取或处理。
- PNG、JPEG、WebP、GIF：每张最多 5 MB，发送给所选模型，需要模型支持视觉输入。
- 音视频（如 MP4、MKV、MOV、MP3、WAV、M4A、FLAC）：只把本地绝对路径、文件名、类型和大小提供给模型，不读取、复制或上传媒体内容，不受图片附件大小限制。可直接说「把这个视频转成字幕」或「提取这段视频的音频」，助手会调用现有 MCP 工具处理。原文件需保留在该路径。
- 不支持 PDF、Word、表格、代码等通用文档附件。

只有图片副本缓存在本机并作为内容发送给所选 AI 服务。其他附件仅保存路径和基本信息，文件内容由 MCP 工具按需处理；原文件需保留在该路径。工具返回的结果可供模型继续处理。

## 编辑、执行与停止

明确的指令直接执行；目标或必要参数不明确时，助手会询问。全部现有 MCP 工具均可按需调用，包括创作、任务控制、服务配置和模型管理。

普通原文字幕任务默认只转写和导出，不会继承上次界面开启的 AI 分段、纠错、说话人识别、配音、合成或参考文稿。要求沿用某个任务或配方时，助手会显式传入它的配置。

要求 AI 分段或纠错时，优先使用任务已配置的精修服务，再使用任务的 AI 翻译服务；未指定且无法解析时，内置助手可以复用当前聊天的 AI 服务。显式指定但不可用的服务不会被自动替换。「保留停顿」本身无需 AI 服务。云语音识别、翻译／精修、配音分别使用对应类型的服务，聊天服务不能代替语音识别或配音服务。

缺少服务、模型、音色或语言不兼容时，工具会返回具体原因和可查询的资源，助手应修正配置或说明缺失项，不应通过悄悄关闭你要求的功能来重试。

助手修改当前字幕后，界面立即更新，并保留在可撤销草稿中。使用编辑器的撤销快捷键即可撤回一次修改。说「保存」才会写入字幕文件。如果等待期间你修改了字幕、切换文档或拆分字幕，旧修改会被拒绝，避免覆盖新内容。

工具卡展示真实执行状态、任务和输出文件。「停止」终止当前 AI 回合，不自动取消已提交的处理任务；可在任务卡中单独取消这些任务。每轮有执行次数上限，到达上限后可发送「继续」。连接异常或软件重启后不会自动重放修改操作。

## 会话历史

点击助手左上角的菜单按钮展开左侧会话历史，默认收起，选择会话后自动收起。聊天记录保存在本机当前配置目录，可新建、切换和删除会话。切换页面、收起面板不会清空对话，重启软件后可继续查看历史。每个会话条目右侧提供删除按钮，无需先切换会话；在条目内确认后删除，历史列表保持展开。运行中的会话不能删除。删除会话只删除聊天记录，已创建的任务和输出文件仍保留。

对话和引用的文本会发送到所选 AI 服务。长字幕按范围读取，较长会话的早期回合会压缩为续跑摘要，本地完整历史仍保留。
