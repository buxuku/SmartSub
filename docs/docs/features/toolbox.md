# 音视频工具箱 (Toolbox)

在日常音视频与字幕处理中，我们常常需要进行一些轻量的前置准备或后置分发操作——比如切掉片头片尾、从视频中抽取纯音频供识别、将内封软字幕提取出来、修复从网上下载的字幕乱码、或是合并原文与译文为双语字幕。

以往用户需要打开多个复杂的第三方工具甚至编写脚本。**妙幕全新内置「音视频实用工具箱」**，将 8 项高频操作直接整合进软件中。

:::tip 零额外安装体积 · 极速离线处理
工具箱全面复用妙幕内置的高性能 FFmpeg 二进制以及纯本地原生算法库，**不需要额外下载几十兆的外部依赖包**，无需安装 Python 或系统 ffprobe，断网也可极速离线运行。
:::

## 1. 字幕格式与字符编码转换器

解决字幕跨播放器不兼容、Windows 系统 ANSI 乱码以及简繁字体转换的利器。

- **多格式任意互转**：支持 `SRT`、`WebVTT`、`ASS/SSA`、`LRC` 及纯文本 `TXT`（可保留时间轴标记）任意格式互相转换。
- **全自动编码检测与修复**：支持严格的 BOM 探测与原生编码校验，覆盖 `UTF-8`、`UTF-8 BOM`、`GB18030 / GBK`、`Big5`、`UTF-16`。彻底告别 Windows 平台记事本打开全是乱码的问题。
- **OpenCC 简繁高保真转换**：内置常用简体转繁体、繁体转简体、台湾正体及香港常用变体。
- **样式标签一键清洗**：去除各类 ASS/VTT 复杂特效与颜色代码，输出最纯粹的标准台词文本。
- **批量并发与实时预览**：支持多文件同时拖入转换，界面实时展示前 5 句转换前后内容对比。

## 2. 极速无损视频裁剪器

专为字幕前置切片设计的视频修剪工具，支持精准定位并直通字幕转写流水线。

- **两种裁剪模式**：
  - **极速无损流拷贝（Lossless Stream Copy）**：直接复制视频与音频流（`-c copy`），**100% 保留原始画质与原容器封装**，无需重新编码，数秒内即可导出数 GB 大小的片段。
  - **精确重新编码（Accurate Re-encode）**：逐帧解码重新对齐，确保严格的帧级时间精确截取。
- **直观双端拖拽手柄**：
  - 拖动左端 `[` 手柄调整截取起点，拖动右端 `]` 手柄调整截取终点，画面实时随滑块逐帧联动。
- **毫秒级数据精准微调**：
  - 入点与出点均配备 `[-1s]`、`[-0.1s]`、`[+0.1s]`、`[+1s]` 步进按钮；
  - 支持直接键盘键入秒数或分秒格式（如 `01:23.5`），回车即刻跳帧生效；
  - 键盘快捷键：`[` 设为入点，`]` 设为出点，`空格` 播放/暂停，`←` / `→` 单帧微调。
- **▶ 预览裁剪选区**：点击即可从入点自动播放至出点并停止，方便剪辑后快速校验成效。
- **直接送入字幕转写**：截取完成后，点击「**直接以此片段新建任务**」，自动打开任务向导并预填裁剪后的媒体文件，无需再次手动找文件导入。

## 3. 音频提取与格式转换器

从各种格式的视频文件中快速抽出音轨。

- **丰富音频格式**：支持导出为 `MP3`、`WAV`、`AAC`、`M4A`、`FLAC`。
- **ASR 语音转写专属预设**：特别内置 **`16kHz 单声道 16-bit PCM WAV`** 规格。该规格是 Whisper、FunASR 等绝大多数本地与云端听写模型的最佳输入标准，能大幅减小处理体积并提升识别稳定性。
- **实时提取进度**：后端实时解析 FFmpeg 时间戳，精准回传提取百分比。

## 4. 容器内封软字幕提取器

许多 MKV、MP4、MOV 等高清视频容器内部封装着官方的多语言软字幕。

- **快速轨位探测**：拖入视频瞬间列出容器内包含的所有字幕轨道、语言标签（如 `chi`、`eng`、`jpn`）及格式（SubRip、ASS、PGS 等）。
- **智能过滤**：默认智能勾选可导出的文本软字幕轨，对位图图形字幕（如蓝光 PGS）给出明确标识。
- **一键批量导出**：多选轨道后，秒级解封装并保存为外部独立的 `.srt`、`.ass` 或 `.vtt` 文件。

## 5. 字幕时间轴校准与防漂移

解决字幕不同步、越往后播放音画偏差越大的常见难题。

- **整体时间偏移（Offset）**：全篇整体提前或推迟指定毫秒，支持快速 `±100ms` / `±500ms` / `±1000ms` 微调。
- **帧率转换缩放（FPS Stretch）**：针对电影与电视版本不同引发的匀速漂移，内置 `23.976 fps ↔ 25 fps`、`24 fps ↔ 25 fps`、`29.97 fps ↔ 25 fps` 等标准重采样比例。
- **首尾双锚点线性拉伸**：输入当前字幕第一句与最后一句在视频中的实际时间，算法自动按斜率对全篇每一句进行线性重采样校正。

---

## 6. 双语字幕智能合并与拆分

- **双语智能合并**：
  - 基于时间轴区间重叠算法（Overlap IoU），自动计算两份单语字幕（如中文与英文）的对应关系；
  - 智能处理两份字幕断句时间略有偏差的情况；
  - 灵活定制排列版式：上原下译、上译下原，支持自定义连接换行符。
- **双语字幕拆分**：
  - 针对同一字幕块包含两行不同语言的已有双语字幕，一键将其拆分分离为两个独立的单语字幕文件。

## 7. 社交分享轻量视频压缩

- **微信分享专属预设（`< 25MB`）**：自动基于视频时长精细计算视频与音频综合比特率，并将分辨率自适应缩放至适合移动端观看的尺寸，确保压制后体积控制在 25MB 以内，无需开通大文件传输即可在微信直接发送。
- **社交 1080p / 720p 预设**：采用高压缩比 x264 编码，在视觉无损的前提下压缩 50% ~ 80% 的体积。
- **目标体积模式**：支持手动指定目标大小（MB），自动规划码率分配。

---

## 8. 视频转高清 GIF 制作器

- **双通道 PaletteGen 算法**：
  - 第一阶段：全面分析选定区间的颜色分布，生成针对当前画面的专属调色板；
  - 第二阶段：使用 Bayer 抖动算法结合调色板渲染 GIF。彻底消除了传统 GIF 制作常见的大面积噪点、杂色与色阶断层。
- **参数自由定制**：支持调整动图输出宽度（如 320px、480px、640px）与帧率（10 / 12 / 15 / 24 fps），轻松兼顾动图流畅度与文件体积。

## 如何使用工具箱

1. **左侧主导航**：点击左侧流水线导航栏底部的 **「工具箱」**（方块图标）即可进入工具箱控制台。
2. **全局命令面板**：在软件任意界面按下快捷键 **`⌘K`**（Mac）或 **`Ctrl+K`**（Windows/Linux），输入工具名称（如“裁剪”、“提取音频”、“转换字幕”）即可快速直达目标工具面板。
3. **工具面板深链**：每个工具均支持 URL 直接访问（如 `/zh/toolbox?tool=videoTrimmer`），在浏览器与工作区之间可随时切换。
