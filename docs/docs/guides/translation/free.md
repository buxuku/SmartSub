不想注册任何服务？装好妙幕就自带四个免费翻译选项：

| 服务                     | 说明                                                                                            |
| ------------------------ | ----------------------------------------------------------------------------------------------- |
| **自动免费翻译**（推荐） | 聚合多个免费源，**一个失效自动切换下一个**，内置限速保护；默认顺序：有道 → 必应 → 谷歌 → DeepLX |
| 有道免费翻译             | 单独使用有道的免费接口：整批一次翻译，速度最快；质量略低于必应，适合草稿                        |
| 必应免费翻译             | 单独使用必应的免费接口：译文质量较好，逐条请求、速度较慢                                        |
| 谷歌免费翻译             | 单独使用谷歌的免费接口：优先整批翻译，被限流时自动改为逐条（部分网络环境需代理）                |

:::caution 有道免费源：非官方接口，不承诺可用性
有道免费翻译基于有道网页版翻译的接口，**并非官方开放的服务**，随时可能变化或失效，**不承诺可用性**。翻译时字幕文本会发送到有道服务器（必应、谷歌同理），涉及保密内容请改用[本地 Ollama](./ollama) 等离线方案。

在「自动免费翻译」里，有道失效时会自动切换到必应、谷歌等下一个源，连续失败后还会暂停使用有道约 2 分钟，不会拖慢整批翻译；单独选用有道时没有后备源，失效后任务会报错——请改用「自动免费翻译」，或换成 [AI 翻译](./overview#按需求推荐)等其它[翻译服务](./overview)。
:::

:::caution 谷歌免费源：两条通道都是非官方接口
谷歌免费翻译有两条通道：**整批通道**一次请求翻译一整批字幕，**逐条通道**一条字幕一个请求。它们都是谷歌翻译的**非官方接口**，随时可能变化或被限流，**不承诺可用性**；翻译时字幕文本会发送到谷歌服务器。

默认先走整批通道；这条通道被限流（429）或出错时，这一批自动改走逐条通道。被限流的通道会暂停 10 分钟起，反复被限会逐步延长、最长 60 分钟，暂停结束后只放行一个探测请求，成功即自动恢复；普通错误则是连续失败 3 次后暂停约 2 分钟。两条通道都暂停时，「自动免费翻译」会先跳过谷歌、改用下一个源；单独选用谷歌时没有后备源，任务会报错——请改用「自动免费翻译」，或换成[谷歌翻译（Cloud Translation）](./google)等其它[翻译服务](./overview)。
:::

## 各免费源对比

| -------- | ---------------------------------------------------- | ----------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **有道** | 速度快，质量略低于必应，适合草稿；默认排在回退链首位 | 国内网络可直接使用，海外网络尚未验证                  | 一次请求翻译一整批（建议 30 条左右），自动校验条数与顺序，对不上时改为逐段重试                                                                                 | 句中的强调标签（如 `<i>never</i>`）可能丢失；没有标点的长句质量下降；仅支持 16 种常见语言，其余语言自动交给下一个源（见下方「有道的语言支持」） |

| **谷歌** | 语种覆盖较广                                         | 部分网络环境需代理（「设置 → 网络代理」）             | 优先整批通道：一次请求翻译一整批（建议 20 条左右，超过 50 条或文本较长时自动拆成多个请求）；整批通道被限流或出错时，该批改走逐条通道，此时批量数只影响进度粒度 | 两条通道都是非官方接口，被限流的通道会暂停约 10 分钟；量大时请配合请求间隔，避免被限流                                                          |

### 有道的语言支持

有道免费源覆盖简体 / 繁体中文、英、日、韩、法、德、西、俄、意、荷、印地、泰、越南、印尼、阿拉伯语共 16 种；葡萄牙语只能作为原文语言。不在其中的语言（如土耳其语、波兰语）在「自动免费翻译」里会自动交给必应等下一个源，单独选用有道时则会提示不支持该语言。

## 在妙幕中配置

默认已就绪，无需任何配置。想微调时在「翻译」页面选中对应服务：

  <img src="/img/v3/translation/auto-free.webp" alt="自动免费翻译配置：回退链与每分钟最大请求数" />
</div>

- **回退链**（自动免费翻译）：源的尝试顺序，失败自动切换。默认是「有道 → 必应 → 谷歌 → DeepLX」，其中 DeepLX 未配置端点时自动跳过；更看重译文质量，可以把必应移到最前
- **每分钟最大请求数**：限速保护，避免被接口封禁；批量任务偶发失败时调低它
- **谷歌的批量与请求间隔**：批量数建议 20 左右；请求间隔和每分钟最大请求数都按「请求」计——整批通道一个请求翻译一整批，逐条通道一条字幕一个请求，所以同样的间隔下整批通道快得多

## 使用建议

- 免费接口为公共资源，**质量与稳定性不做保证**：正式发布内容建议用 [AI 翻译](./overview#按需求推荐)复核或[校对台](/features/proofreading)过一遍
- 有道速度快，适合先出草稿再到校对台精修；它在翻译前会保护字幕里的 `<i>`、`{\an8}` 等格式标记、♪ 与对白短横线，翻译后原样还原
- 免费源不支持[术语表](/advanced/glossary)注入（那是 AI 翻译的能力）
- 大批量高频使用请自觉控制速率，或改用按量计费的正规服务
