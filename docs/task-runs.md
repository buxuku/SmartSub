# 任务运行、暂停与重新执行

每次开始任务会创建一轮独立运行，固定本轮配置和输入文件。排队、执行、暂停、取消处理中，以及等待人工校对时，不能修改配置或文件集合。暂停会等待当前阶段结束并保存结果，然后释放文件并发槽；恢复从下一阶段继续。

多文件批次中，已到人工检查点的文件可以先校对、保存和放行，其他文件继续执行。只允许编辑停在检查点的文件结果，任务配置仍保持锁定。只要还有运行中或可运行的文件，整批状态仍为进行中；自动化 `tasks.get` / `tasks.wait` 会及时返回待审阅信息，同时保留后台执行和取消能力。单个文件失败也不会提前终止其余文件，整批结束后再提供失败重试。

配置工具栏始终使用相同的表单；处理中禁用，已完成、失败、中断或取消后自动恢复可编辑。可以直接调整参数，再点击「重新处理」，循环改善结果。参数修改会自动保存，重新打开任务时恢复，并且不会改变上一次结果对应的执行配置。

含配音或视频合成的任务显示配方名称或完整流程名称，参数按「字幕与翻译」「配音」「视频合成」「流程设置」分组，只出现任务已有的环节。处理中仍可切换分组查看，字段保持禁用。结束或取消后，可直接修改音色、语速、字幕样式、画质、编码和人工确认选项，然后重新处理。普通字幕任务保留紧凑工具栏。

创建向导与任务页共用配音、合成和流程设置控件。修改只影响当前任务，不会覆盖来源配方。任务保存的样式副本不会随预设变更而被替换；服务或音色暂不可用时，保留原选择并提示处理。当前版本支持调整已有阶段的参数，增减配音和合成阶段仍通过新建任务选择。

「重新处理」会重新评估列表中的所有文件，包括已经完成的文件。失败或中断时，如果配置和输入都没有修改，也可以选择「重试失败阶段」，继续原运行并保留原配置及已提交结果。修改参数或文件后，重试入口会按新配置重新评估所有文件；取消后重新开始也会创建新运行。

每轮都会完整读取媒体并计算 SHA-256，字幕和参考文稿则保存独立副本。文件在处理期间被替换时停止处理，避免混合新旧内容。阶段参数、有效全局设置、服务商参数、词库、输入和上游产物共同决定能否复用。只有上一轮中已完整提交、校验通过的自动结果可复用；损坏、缺失、未完成和降级结果会重新执行。外部 Whisper CLI 无法可靠识别其外部实现版本，因此不跨运行复用其听写结果。

列表中的文件名、进度和操作独占一行，阶段排列在下方并按窗口宽度换行。阶段用图标区分执行、复用、无需执行和降级，悬停可查看说明。只更改后续参数时，可复用未受影响的上游阶段。模型和服务依赖在确实需要执行该阶段时检查；复用结果不需要重新调用付费服务。

任务页不显示运行历史管理面板，历史配置、阶段记录和结果位置仍在内部保留，用于复用和排查。修改下一次处理的参数不会改变旧结果的校对和导出方式。历史校对和配音编辑不会自动带入新运行；同一轮在人工检查点保存并确认的修改会用于后续处理。配音确认后才构建用于交付和视频合成的音轨。交付文件遇到同名文件会使用新名称，不覆盖已有文件。

运行清单、自动产物和独立的可编辑校对版本保存在统一存储目录的 `task-runs/`；未设置统一目录时使用应用用户数据目录。阶段工作区使用临时目录下的短路径，阶段结束后回收不再被引用的工作文件。转录读取已提交音频，词级时间轴和诊断文件写入当前阶段工作区，避免重复保存音频。

更改目录后，新运行使用新位置，已有运行保持原位置并继续支持重试、校对和复用。设置页「任务数据」可预览并安排下次启动迁移：逐文件校验、更新路径引用后才删除旧副本；中断会按日志恢复。迁移暂停及待审核任务不会自动恢复执行。请使用应用迁移入口，不要直接搬动包含绝对路径引用的任务目录。

删除任务先提交索引变更，再回收无外部引用的运行目录。仍被历史任务、独立校对、配音或草稿引用的数据保留；损坏或未知元数据会阻止回收。设置页提供安全清理入口。用户交付文件不会被删除，也不按时长或容量自动淘汰仍被引用的历史产物。旧任务的导出和配音续跑通过兼容路径保留，旧记录不会直接作为新缓存的可信来源。

大批量任务的进度和活动状态先在内存合并，每 200 毫秒至多发布一次进度快照，合并发生在整批数据克隆和界面投影之前。纯进度检查点每 2 秒保存一次；阶段结果、暂停、取消和人工确认仍立即保存，正常退出会补存尚未落盘的进度。50 个及以上文件的列表视图只渲染可见行和少量相邻行，按实际行高保持滚动位置。任务日志面板只保留最近 200 条，完整日志仍按原规则写入应用日志文件。

主界面进程意外退出时提供原生恢复提示，可以重新加载当前任务页面并读取后台状态。恢复界面不会重新派发任务，也不会自动循环重载。这降低大批次的界面与 IPC 负载，并提供白屏后的恢复途径；issue #574 中 Chromium 共享内存句柄校验失败的上游原因仍需在 Linux 现场继续验证。

开发验证入口：`test:task-runs`、`test:stage-artifacts`、`test:stage-cache`、`test:e2e:task-runs`。Electron 验收使用隔离用户目录、现场生成的媒体及字幕、本地模拟翻译和配音服务，覆盖历史与草稿、删除后重启、格式变更复用、校对保存后放行及配音确认后构建音轨，无付费服务调用。真实云服务、各平台 GPU 和完整本地模型推理仍需对应环境验证。
